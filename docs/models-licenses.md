### Changes made to the NASA models (with `npm run optimize`)

- Re-compressed from Draco to Meshopt, so the viewer needs no decoder download.
- Removed unused data, merged duplicate data, and removed the duplicate JPEG and PNG copies of the textures that Ingenuity carried next to its WebP ones (1.93 MB → 387 KB).
- **No geometry was removed.** Triangle counts are unchanged: Opportunity 3,845, Ingenuity 9,124.
- No NASA logos or insignia were found in either model's geometry. Neither model has a texture that was checked for a logo beyond Ingenuity's 8 textures, so a second reviewer should look at it in the viewer.

## What the rules say (checked 14 Nov 2026)

From [NASA Images and Media Usage Guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/):

- NASA content, including "files used to render 3D models", is generally not subject to copyright in the United States, and may be used for educational or informational purposes without asking permission.
- **Credit NASA** as the source.
- Do **not** suggest NASA endorses this project.
- The NASA **insignia, logotype and identifiers** are protected and are not public domain. Do not put NASA logos on the models or the page without clearance.
- Anything NASA marks as **copyrighted by a third party** is not free to use. Check each model's own page.

From the [NASA 3D Resources repository](https://github.com/nasa/NASA-3D-Resources): "These assets are free and without copyright."
The catalogue at [science.nasa.gov/3d-resources](https://science.nasa.gov/3d-resources/) says every asset is free to download and use.

Neither model's folder contains its own README or licence file, and neither is marked as third-party. The repository README lists no per-model exceptions.

### The Lunar Roving Vehicle: what we did

The PRD locks the LRV as **Core 2**, and only Core 3 has a named fallback. The options were: (1) keep looking, (2) build our own, (3) use a third-party model. Third-party models found were paid or user-uploaded, and the PRD says to use "only NASA-published or clearly licensed assets", so that option was dropped.

**We chose option 2:** the team built its own LRV (`scripts/make-lrv.mjs`). It carries no third-party rights.

- It is **an illustration, not a NASA model**. The interface and the credits must not describe it as one.
- **Still worth doing:** I only searched the GitHub repository and one web search. NASA's own [3D Resources site](https://science.nasa.gov/3d-resources/) could list a rover model the repository doesn't. The old nasa3d.arc.nasa.gov address now just redirects there. If a mentor finds one, drop it into `models-src/lrv.glb`, run `npm run optimize`, and update this file.
- The proportions are rough and the detail is simplified (no wiring, hinges or fine mesh). It should be described as "a simplified model".
- The shapes were built from the vehicle's published layout and general knowledge, not from a particular NASA drawing, so a second person should compare it with NASA's photos of the vehicle before submission.

## Credit wording

Use this pattern in the interface (Source Credits already reads from `missions.json`). The existing credits in `missions.json` name other sources for the 3D models ("NASA Visualization Technology Applications and Development (VTAD)", "NASA 3D Resources / Marshall Space Flight Center", "NASA/JPL-Caltech"). **Those do not match what I downloaded**, and I could not confirm any of them from the repository, which names no author or centre per model. Suggested wording, to replace them:

> Opportunity and Ingenuity: 3D model by NASA, from NASA 3D Resources (github.com/nasa/NASA-3D-Resources). Resized and compressed for the web.
>
> Lunar Roving Vehicle: simplified 3D model built by the project team. Not a NASA model.
