## 1. 3D Model Assets & Attribution

The project features three mission-related 3D models representing historical and modern planetary exploration equipment.

| Asset | Creator / Source | Attribution |
|---|---|---|
| Opportunity Rover | NASA 3D Resources | NASA |
| Ingenuity Mars Helicopter | NASA 3D Resources | NASA |
| Lunar Roving Vehicle (LRV) | UA VEYLORA Project Team | Original project-created geometry |

### 1.1 Opportunity Rover

- **Asset:** 3D Model of Opportunity Rover
- **Original source:** NASA 3D Resources
- **Attribution:** NASA
- **Source repository:** [NASA 3D Resources — Opportunity Rover](https://github.com/nasa/NASA-3D-Resources/tree/master/3D%20Models/Mars%20Exploration%20Rover%20-%20Opportunity%20(MER-B))

The model represents NASA's Opportunity Mars Exploration Rover.

### 1.2 Ingenuity Mars Helicopter

- **Asset:** 3D Model of Ingenuity Mars Helicopter
- **Original source:** NASA 3D Resources
- **Attribution:** NASA
- **Source repository:** [NASA 3D Resources — Ingenuity Mars Helicopter](https://github.com/nasa/NASA-3D-Resources/tree/master/3D%20Models/Ingenuity%20Mars%20Helicopter)

The model represents NASA's Ingenuity Mars Helicopter.

### 1.3 Lunar Roving Vehicle (LRV)

- **Asset:** Simplified 3D Model of Lunar Roving Vehicle
- **Creator:** UA VEYLORA Project Team
- **Modeling contribution:** Sunaila Ilyas (3D Developer)
- **Asset type:** Original project-created geometry
- **Attribution:** UA VEYLORA

The Lunar Roving Vehicle model is custom geometry created by the project team. It is not represented as an official NASA 3D model.
